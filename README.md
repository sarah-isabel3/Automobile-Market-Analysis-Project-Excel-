# 🚗 Automobile Data Analysis – Excel Dashboard Project

## 📊 Overview
This repository contains an Excel-based analysis of an automobile dataset focused on identifying patterns that help guide decisions for new car model launches, fuel efficiency optimization, and manufacturer selection.  

The project uses **Pivot Tables**, **Pivot Charts**, **Scatter Plots**, and **Descriptive Analysis** to uncover insights about car manufacturers, body types, mileage patterns, and fuel economy.

---

## 📁 Project Structure


---

## 🎯 Objectives
- Identify the **most diverse manufacturer** in terms of body type offerings.
- Analyze **fuel efficiency vs engine displacement** trends.
- Compare **city mileage vs highway mileage** to understand driving behavior.
- Determine the **best-performing body type** and fuel type combinations.
- Recommend suitable **car manufacturers and models** for future launches.
- Provide actionable insights supporting **carbon emission reduction** strategies.

---

## 📌 Key Analyses Performed

### **1️⃣ Manufacturer Diversity Analysis**
- Used Pivot Table → `Make` vs `Body_Type`, with **Count of Body_Type**  
- Bar chart highlights manufacturers with the widest variety of models.  
- Insight: *Suzuki and BMW offer the highest body-type diversity in the dataset.*

---

### **2️⃣ Fuel Efficiency vs Engine Displacement**
- Scatter plot comparing `Displacement` (cc) vs `Fuel_Efficiency`  
- Helps identify whether larger engines truly reduce mileage.  
- Insight: *Moderate negative correlation — compact engines are more efficient.*

---

### **3️⃣ City Mileage vs Highway Mileage**
- Scatter plot: `City_Mileage` vs `Highway_Mileage`  
- Reveals real-world vs long-route efficiency.  
- Insight: *Most models maintain a proportional increase; hatchbacks perform best.*

---

### **4️⃣ Average Fuel Efficiency by Body Type & Fuel Type**
- Combination pivot chart: Avg Fuel Efficiency by Body Type → grouped by Fuel Type  
- Shows which segment-fuel combination provides the best performance.  
- Insight: *Hybrid hatchbacks and compact SUVs show highest mileage.*

## 🔍 Key Insights Summary
- **Top Manufacturer:** Suzuki (most diverse and fuel-efficient lineup)  
- **Best Efficiency Segment:** Hatchbacks / Compact Crossovers  
- **Best Fuel Type:** Hybrid > Clean Diesel > Petrol  
- **Displacement Effect:** Smaller engines show significantly higher mileage  
- **Driving Pattern Insight:** Highway mileage is consistently better → good for long-route customers
